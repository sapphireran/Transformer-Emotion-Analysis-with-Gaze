How to read this
----------------
* majority / length: is the label just the most common class or review length?
* gaze: five reading-time z-scores, no words.
* text: hashed n-grams, no gaze.
* fusion: concat of text block and gaze block (late fusion).
* If fusion ≈ text and gaze ≈ majority, RoBERTa+gaze is unlikely to be magic.
* If gaze is strong, look for length leakage before celebrating.
* This is not a substitute for model_ZuCo_SST.py.

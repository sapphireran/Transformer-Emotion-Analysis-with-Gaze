# Datasets

Personal notes on the tables that are actually in this clone. Counts
come from `examples/01_repo_inventory.py` and `examples/06_split_and_schema.py`.

## ZuCo–SST overlap (400)

Movie-review sentences that also appear in the ZuCo normal-reading
recordings. Twelve readers. Sentence-level eye-tracking is averaged
(see [subject alignment](subject-alignment.md) before trusting that
average), then z-scored.

| file | rows | role |
| --- | ---: | --- |
| `ZuCo_SST_data/combined_sst_et_standard.csv` | 400 | What `model_ZuCo_SST.py` reads |
| `ZuCo_SST_data/combined_sst_et_min_max.csv` | 400 | Same text, min-max gaze |
| `ZuCo_SST_data/ssts_ZuCo.csv` | 400 | Text + label only |
| `ZuCo_SST_data/train.csv` | 320 | Leftover 80% split |
| `ZuCo_SST_data/valid.csv` | 40 | Leftover 10%, **not stratified** |
| `ZuCo_SST_data/test.csv` | 40 | Leftover 10% |

Label counts on the combined table: **123 / 137 / 140**
(negative / neutral / positive). Almost balanced.

The 320/40/40 files partition the 400 ids with no overlap. The 5-fold
script ignores them. The 40-row valid split is 7 / 14 / 19 — a 5-point
accuracy change is two sentences.

Sentence ids are `0..399`.

## Per-reader ZuCo

| file | rows |
| --- | ---: |
| `ZuCo_et_csv_data/{1,2,4–12}_SR.csv` | 400 each |
| `ZuCo_et_csv_data/3_SR.csv` | **299** |
| `ZuCo_et_csv_data/average_data.csv` | 400 |
| `ZuCo_et_csv_data/standard_scaled_average_data.csv` | 400 |
| `ZuCo_et_csv_data/word/{1–12}_SR.csv` | 7129 for reader 1, 5293 for reader 3 |
| `ZuCo_et_csv_data/word/word_averages_v2.csv` | 7129 (400 sentences) |

Subject file `3_SR.csv` is task-1 subject index 2 in `utils_ZuCo.py`.
That transformer drops original sentences 150–249 and 399, then
reindexes. Word-level `Sent_ID` values are compacted the same way
(`150_NR` in file 3 is original sentence 250).

`standard_scaled_average_data.csv` matches the gaze columns of
`combined_sst_et_standard.csv` on sentence 0 (`nFixations = 1.5209`).
The training table is this average, joined to text and labels.

## Full SST with projected gaze (11,853)

| file | rows | labels 0/1/2 |
| --- | ---: | --- |
| `SST_data/combined_full_sst_et.csv` | 11,853 | 4649 / 2241 / 4963 |
| `SST_data/train_full_sst.csv` | 9,482 | 3710 / 1833 / 3939 |
| `SST_data/valid_full_sst.csv` | 1,185 | 476 / 209 / 500 |
| `SST_data/test_full_sst.csv` | 1,186 | 463 / 199 / 524 |
| `SST_data/stts_all_sentence_level.csv` | 11,853 | no header; `sentence,POLARITY` |

The 80/10/10 split is disjoint and covers the combined table.
Neutral is under-represented (~19%). Gaze columns are `nFix, GD, TRT,
FFD, GPT` and are already standardized (mean 0, std 1) but they are
**not** twelve-reader recordings of the full SST.

`SST_data/sst_et_test.csv` is a word-level placeholder with zeros in
every gaze column — a leftover of `convert_sst_to_et.py`.

## The two tracks barely share text

After lowercasing and stripping slashes, **three** sentences appear in
both combined tables, and their labels agree:

- `... a roller-coaster ride of a movie` (positive)
- `girls gone wild and gone civil again` (neutral)
- `under-rehearsed and lifeless` (negative)

Do not treat the 400-row ZuCo set as a subset of `combined_full_sst_et.csv`.

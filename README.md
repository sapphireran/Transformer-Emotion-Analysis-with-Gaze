# Transformer emotion analysis with gaze

Personal research checkout: late-fusion BERT/RoBERTa plus five
eye-tracking channels, on two **different** tables.

| Track | Table | Gaze | How the original trainer evaluates |
| --- | --- | --- | --- |
| ZuCo ∩ SST | 400 sentences | recorded, 12 readers | 5-fold CV (`model_ZuCo_SST.py`) |
| Full SST | 11,853 sentences | projected, column `nFix` | 80/10/10 (`model_full_SST.py`) |

There was no README on `main`. This branch adds a personal lab book,
stdlib+NumPy examples, and tests that lock numbers measured on the
committed CSVs. Training-script behaviour is unchanged.

## Read this before quoting a number

1. **Reader 3 is compacted, then averaged by row index.**
   `ZuCo_et_csv_data/3_SR.csv` has 299 rows because MATLAB task-1 subject
   2 dropped sentences 150–249 and 399. Compact id 150 is original
   sentence 250 (`SentLen` 15 vs 9). The published mean at id 150 is
   **9.5 words** — eleven 9s and one 15. Remapping changes nFixations on
   246 / 400 sentences. Details: [`docs/03-reader3-forensics.md`](docs/03-reader3-forensics.md).
2. **`model_full_SST.py` prints test metrics on the last 162 / 1,186 rows.**
   The test loop assigns `all_preds = …` instead of `extend`. Validation
   is fine. Details: [`docs/08-trainer-errata.md`](docs/08-trainer-errata.md).
3. **Projected full-SST gaze is almost rank-1.** Correlation condition
   number ≈ 1.4×10⁴ vs ≈ 300 on recorded ZuCo. A `Linear(5→16)` stem
   cannot invent four extra channels. Details: [`docs/05-predicted-gaze-degeneracy.md`](docs/05-predicted-gaze-degeneracy.md).

HTML copy of the same notes: [`docs/labbook.html`](docs/labbook.html)
(regenerated by `examples/10_build_labbook.py`).

## Personal examples (CPU, no Hugging Face)

Needs Python 3.10+ and NumPy.

```bash
python3 -m pip install -r requirements-examples.txt
python3 examples/run_all.py
python3 -m unittest discover -s tests -v
```

| script | what it checks |
| --- | --- |
| `01_inventory.py` | row counts / schemas / label mix |
| `02_reader3_forensics.py` | compact→original map, SentLen 9.5, word-stream cut at 2594 |
| `03_word_token_census.py` | `emp11111ty`, `murderoncampus`, 55 `unknown`/`WordLen=0` |
| `04_gaze_rank_and_collinearity.py` | corr matrices + eigenvalues |
| `05_reader_reliability.py` | pairwise r / ICC(1) on sentences 0–149 only |
| `06_join_and_scalers.py` | text⨝z-score join, min-max / ddof=0 fingerprints |
| `07_split_and_trainer_errata.py` | unused 7/14/19 valid split, last-batch 162 |
| `08_cpu_baselines.py` | majority / gaze / hashed text / concat / shuffle |
| `09_sentence_walkthrough.py` | sentences 4, 3, 80 at word level |
| `10_build_labbook.py` | writes `docs/labbook.html` |

Snapshots from a local run: `examples/output/`.

## Original trainers (GPU / weights, unchanged)

```bash
# ZuCo 400, model_type in {bert, roberta, bert_eye_tracking, roberta_eye_tracking}
python3 model_ZuCo_SST.py

# full SST — create models/ first; do not quote the test line as 1186 rows
mkdir -p models
python3 model_full_SST.py
```

Those scripts want `torch`, `transformers`, `datasets`, `pandas`,
`scikit-learn`, `tqdm`. They are not installed in this notes environment
and are not imported by the examples.
